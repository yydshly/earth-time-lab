# 同刻 · 地球时区实验室

从此刻的全球时间出发，通过交互地球、入门课、文字理论、公告换算和约时间工具，理解“同一个瞬间，世界各地分别几点”。第一版 1.0.0 已定稿，暂不继续扩展功能。

- [在线体验](https://yydshly.github.io/earth-time-lab/)
- [GitHub 仓库](https://github.com/yydshly/earth-time-lab)

在线版完全静态运行，已包含 **185 段 MiniMax 预录音频**，无需 API 密钥。涉及当前时间、公告和个人设置时，语音讲解如何读屏幕，具体日期、钟点和换算结果由画面实时计算；在线版不实时生成语音，也不上传公告或个人作息供语音合成。

## 如何体验

首次使用可点击“跟着地球看一遍”，完整了解各项能力；也可按需要直接进入：

| 模块 | 用途 |
| --- | --- |
| 此刻全球时间 | 对照北京与全球重要地域，理解当地日期、钟点、UTC 偏移和清晨、午后等时间阶段 |
| 地球入门课 | 按 8 课逐步认识时间写法、自转、UTC、跨日、时区边界、夏令时、作息与约时间；另有 62 章国家和城市巡游 |
| 认识时区 | 7 个文字理论主题，可从课堂或工具直达对应解释，再返回原场景 |
| 读懂全球重置公告 | 粘贴常见时间表达，核对日期和时区，查看北京时间、UTC、截止边界及全球对照 |
| 世界作息 | 对照 9 座城市的地域生活示意与可修改的具体人物设置，区分当地习惯和个人差异 |
| 找个好时间、沟通指南 | 寻找共同空档，生成中英文确认句和一次性 `.ics` 日历文件，不会自动发送邀请 |

公告中普通的“太平洋时间 / PT”，以及未明确强调固定偏移的“PST / 太平洋标准时间”，默认按洛杉矶的**太平洋当地时间 PT**理解，并按事件日期使用 PST（UTC−08:00）或 PDT（UTC−07:00）。原文写 PST 时保留这一解释提示，严格 PST 作为补充对照；两种解释在夏令时期间相差一小时。明确写固定 UTC 偏移、严格 PST，或手动选择严格 PST 时，按其明确规则换算。

“午夜前 / before midnight”表示截止边界，不代表某个精确的恢复时刻。含“今天、明天、周五”等相对日期的公告，按公告时区解释；未提供发帖时间时默认以识别时刻为发布时间，并显示假设供核对。格式不足或有歧义时需要补充字段，不能据此确认某个账户的实际额度规则。

## 本机运行

需要 Node.js，建议使用 Node.js 22。项目没有需要安装的 npm 依赖，浏览器渲染依赖已保存在仓库中。

Windows 可双击 `启动同刻.cmd`，或在项目目录运行：

```sh
npm start
```

打开 [本机页面](http://127.0.0.1:4318/)。服务只监听 `127.0.0.1`；可通过 `PORT` 调整端口。Windows 启动器在后台启动服务，双击 `停止同刻.cmd` 可停止本目录启动的服务。电脑重启后需重新启动；直接双击 HTML 无法正常加载模块和地图。

`npm start` 启动的是保留可选动态语音能力的本机版。若只想体验与在线版相同的预录行为，请使用下方静态预览命令。

## 开发、检查与静态发布

页面使用 HTML、CSS 和 ES Modules；`dist/` 是手写页面源码，必须随仓库提交。`public/` 保存经过筛选的公开音频与预录索引。详情见 [项目结构](docs/project-structure.md)。

```sh
npm test
npm run check
npm run build:pages
npm run verify:pages
npm run preview:pages
```

构建把页面、公开索引和白名单音频写入 `.release/site/`，注入预录模式标记并调整 GitHub Pages 子路径资源引用，不修改本机页面源码。预览地址为 [静态预录版](http://127.0.0.1:4321/earth-time-lab/)，可通过 `PREVIEW_PORT` 调整端口。静态预览没有语音 API 后端。

仓库已经包含在线版需要的公开音频，日常构建、预览和 GitHub Pages 部署不需要 MiniMax 配置，也不会消耗语音额度。推送到 `main` 后，GitHub Actions 执行测试、语法检查、构建与产物验证，再发布到 Pages；部署不使用 MiniMax 密钥。

仅在修改公开讲稿后需要重新准备音频：先启动并配置本机语音服务，再运行 `npm run prepare:recorded`，完成后重新构建与验证。该命令会检查或生成公开讲稿对应的音频，缺少的音频可能消耗 MiniMax 账户额度。不要把整个 `.voice-cache/` 复制到公开目录，其中可能包含个人输入生成的音频。

## 可选的本机 MiniMax 语音

在线体验无需进行这一节的配置。本机如需按当前日期、钟点或人物设置生成语音，可参考 [.env.example](.env.example)，在私有配置文件中设置 MiniMax 密钥、模型和音色，再用 `MINIMAX_CONFIG_PATH` 指向该文件，例如 `C:/path/to/private/.env.minimax`。也可在私有 `.voice-settings.json` 中设置 `configPath`；配置文件和密钥都不要提交到 Git，也不要放进 `dist/` 或 `public/`。`server.mjs` 不会自动加载项目根目录的 `.env`。

本机动态模式由本地服务读取密钥，网页不会获得已保存的密钥。动态合成文本会发送给 MiniMax；相同文本、模型和音色复用本机缓存。切换页面、参数或音色会停止旧播放；已经开始的后台合成可能继续完成，停止播放不等于取消账户用量。

固定课程可分别通过 `generate:tour`、`generate:lessons`、`generate:routines`、`generate:human`、`generate:resets` 准备音频；对应的 `verify:*` 命令需要本机安装 `ffprobe`。这些是本机内容维护工具，不是在线运行所需步骤。所有语音均为 AI 合成中文讲述。

## 数据、隐私与范围

- 时间计算使用浏览器 `Intl` 与 IANA 城市时区，时区规则取决于设备时区数据库。明确区分不存在、重复的夏令时钟点；未来规则变化需要设备更新。
- 时间阶段只说明当地钟点，不判断具体的人在做什么。地域生活环是工作日教学示意，不是国家人口统计；人物为可修改的虚构示例，联系前仍需确认个人可用时间及假日。
- 个人作息和规划器设置保存在当前浏览器；课程链接保留教学位置，不包含完整个人表单。公告提取和时间换算在浏览器本地进行，不读取产品账户或额度余额。
- 昼夜和太阳时用于教学近似，15° 分带不是现实边界。时区地域图层用于地球尺度观察，不是精确行政或法律依据。
- 地图、贴图与 Three.js 模块随仓库提供，无运行时 CDN 依赖。NASA Blue Marble 地表为合成影像，不是实时卫星画面；地图和音频仍需从网站加载。

原始资料入口见应用“数据与来源”和 `dist/learning-data.mjs`；第三方资产来源及许可说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
